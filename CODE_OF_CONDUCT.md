# Code of Conduct

We are committed to a respectful, harassment-free project for everyone.
Contributors must communicate constructively, respect privacy and consent,
credit sources, and avoid publishing real sensitive data or weaponized samples.

Unacceptable behavior includes harassment, discriminatory language, threats,
doxing, deliberate disruption, or using project channels to facilitate abuse.
Maintainers may edit or remove contributions and restrict participation when
needed to protect the community.

Report conduct concerns privately through the repository owner's GitHub contact
or the security reporting path in [SECURITY.md](SECURITY.md). Reports will be
handled as confidentially and promptly as practical.
